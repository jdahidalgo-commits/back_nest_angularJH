# Comandos GitHub

# Inicializar el repositorio local
```
git init
```

Referencia del repositorio local con el repositorio remoto (GITHUB)
```
git remote add origin https://github.com/jdahidalgo-commits/back_nest_angularJH.git
```
# Validar refenrencia
```
git remote -v
```

git add .
git commit -m "proyecto base"
